Privacy Policy

Hermes Personal Assistant. Last updated October 2026.

Who this app is for

Hermes Personal Assistant is a private app used by one person, its owner, with the owner's own Google account. It has no other users and collects nothing from anyone else.

What it accesses

With the owner's consent, the app can access that account's Gmail, Google Calendar, Google Drive, Google Docs, Google Sheets and Contacts. It uses this access only when the owner asks the assistant to do something.

How data is used and stored

  • Google data is processed on a server controlled by the owner. The app's access token is stored only on that server.
  • Content the assistant reads may be sent to an AI model provider as part of answering the owner's request.
  • Data is not sold, shared with advertisers, or used for advertising.
  • Data is not shared with anyone else, except as needed to run the AI model that handles the owner's own requests.

Google API Services policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

The owner can revoke the app's access at any time at myaccount.google.com/permissions. Deleting the token file on the server also ends access.

Changes

If this policy changes, the date above will be updated.
